# Octopath Traveler II — Knowledge Base

Lore from the Octopath Traveler Fandom wiki, OT2 only. Each file is `<slug>.md` with `name`, `aliases`, and `source` (wiki page titles) in its frontmatter. Links between files are relative paths.

## characters/
- `osvald/`, `temenos/`, `agnea/`, `throne/`, `hikari/`, `ochette/`, `castti/`, `partitio/`: one directory per traveler. It holds the traveler's own file (e.g. `osvald/osvald.md`) and the people in their story (family, allies, rivals, antagonists), grouped by the wiki's "<Traveler>'s Path" lists.
- `side_stories/`: characters from side stories.
- `others/`: characters who cut across stories (e.g. Arcanette, Oboro, Regulus).

## locations/
One directory per region: `brightlands/`, `crestlands/`, `harborlands/`, `hinoeuma/`, `leaflands/`, `totohaha/`, `wildlands/`, `winterlands/`, `sundering_sea/`. Each holds the region overview plus:
- `towns/`: towns, and the areas inside them (named `<town>_<area>`).
- `wilds/`: roads, fields, anchorages, altars.
- `dungeons/`: caves, ruins, castles, and their inner areas.

## world/
- `gods/`: the gods of Solistia, Vide, Galdera.
- `nations/`: Ku, Sa, U, Delstasch, Fj'all.
- `factions/`: orders, guilds, clans, syndicates.
- `species/`: peoples and kinds of creatures.
- `beasts/`: named beasts and monsters.
- `lore/`: concepts, history, and events (One True Magic, the Night of the Scarlet Moon, the Sacred Flame).

## stories/
- `main/`: The Journey for the Dawn (the true ending). The travelers' own chapters are in their character files.
- `next_chapters/`: "<Name>'s Next Chapter" side stories, set after a traveler's story ends.
- `side_stories/`: side stories by region. `the_travelers_bag.md` happens in every region.
- `documents/`: in-game books, journals, and scripts.
