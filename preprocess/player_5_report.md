## Final overlay evidence

All 66 day/night overlays were viewed, edited where necessary, re-rendered, and checked. No final box was judged to overlap a townsperson. This is visual judgment, available for reviewer confirmation; tests validate data rather than image content.

[Browse the 25 final overlay sheets](../output/stand_check/index.html). Individual image overlays use `<place>_<spot>_<day|night>_final.jpg`; sheets use `<place>_final_<number>.jpg`. Re-render a place with `uv run python output/stand_check/render.py <place> final`. The scratch renderer uses the already-installed local Pillow package; project dependencies and image files were not changed.

The review moved boxes off residents in plazas, interiors, balconies, the festival crowd, and wilds ledges. Day/night layouts were checked together, particularly the shrine crowd and chapel altar. Original clear points were retained; replacement feet were placed on nearby visible ground or steps, with scale adjusted where perspective changed.
